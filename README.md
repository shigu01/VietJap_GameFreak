# VietJap

## 1. 作品概要

**VietJap**は、在日ベトナム人を対象とした、代替食材を考慮したレシピ提案Webアプリケーションです。

日本でベトナム料理を作ろうとした際に、母国では一般的な食材が日本では入手しにくいという課題に着目し、日本で入手しやすい食材を使った代替レシピを提案することを目的として制作しました。

2025年のグローバルPBLにおいて、ハノイ工科大学の学生と日本人学生による4人チームで開発しました。

---

## 2. 制作意図

在日ベトナム人が日本でベトナム料理を作る際、「必要な食材が近くの店舗で手に入らない」という問題があると考えました。

そこで、単純にレシピを検索するだけではなく、使用したい食材を日本で入手しやすい別の食材に置き換えたレシピを提案することで、より手軽に料理を楽しめるWebアプリケーションを目指しました。

また、ベトナム人学生との共同開発を通して、日本側だけでは気づきにくい課題やニーズを取り入れることも意識しました。

---

## 3. 主な機能

### レシピ検索

料理名や食材などからレシピを検索できます。

### 代替食材を考慮したレシピ提案

日本では入手しにくい食材を、入手しやすい別の食材に置き換えたレシピを提案します。

### 料理詳細ページ

料理の詳細情報を確認できます。

### 画像ギャラリー

料理に関する複数の画像を閲覧できます。

### カート機能

レシピに必要な食材をカートに追加できます。

### SNS機能

ユーザー同士で料理に関する情報を共有できます。

## 9. 起動方法

### 1. リポジトリを取得

本リポジトリをローカル環境に取得します。

### 2. `source` ディレクトリへ移動

```bash
cd source
```

### 3. 必要なパッケージをインストール

```bash
pip install -r requirements.txt
```

### 4. データベースを作成

```bash
python manage.py migrate
```

### 5. 開発用サーバーを起動

```bash
python manage.py runserver
```

### 6. ブラウザからアクセス

表示されたURLにブラウザからアクセスしてください。
